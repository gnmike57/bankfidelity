The parallel static reports produced useful candidates but also false positives. These items must not appear as verified defects without qualification.

| Candidate | Disposition | Reason |
|---|---|---|
| Offline-parser `amounts.last().unwrap()` panic | Rejected | Control flow checks non-empty amounts before opening/closing access, skips empty transaction rows, and reaches the default match arm only for length three or greater. |
| Native batch editor lacks a non-ASCII guard | Rejected | `src/pdf/native_engine.rs:804-813` explicitly rejects non-ASCII batch replacements. |
| Font synthesis stub silently corrupts production output | Downgraded to dead/incomplete API | `synthesize_font_subset` is exported but has no production caller; active deep-font preflight uses `check_glyph_coverage` and separate Python cascade logic. |

| All Document AI loops are unbounded | Narrowed | Synchronous retries are bounded; only the long-running-operation outer poll lacks an overall deadline. |
| Readiness result loss is currently P0 | Downgraded | The bug is real, but the present HTTP server exposes only health/index/readiness routes, so there is no current remote job caller. It remains an unsafe channel design and future regression trap. |
